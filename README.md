# StockPilot — Smart Inventory & POS Web App

A responsive retail inventory and point-of-sale (POS) web application built with **React**, **Vite**, **HTML**, and **CSS**, designed for store operations such as **NovaMart Retail Store**.

## Live Demo
- **Live App:** https://stockpilot-inventory-app-weld.vercel.app/dashboard

## Key Features
- **Executive Dashboard:** Real-time store operations overview with revenue, gross profit, inventory valuation, low/out-of-stock health metrics, 7-day sales revenue trends, and category valuation charts.
- **Inventory & Restock Alerts:** Tracks low-stock and out-of-stock thresholds with quick restock and reorder workflows.
- **Sales (POS) & Receipts:** Cashier checkout flow supporting multiple payment methods and printable/viewable receipts.
- **Catalog, Categories & Transactions:** Manage products and categories, inspect transaction history, and review operational reports.

## Tech Stack
- **Frontend:** React, Vite, HTML5, CSS3
- **Deployment:** Vercel
